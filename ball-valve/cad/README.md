## 一、CAD 图（DXF）

用 AutoCAD、中望 CAD、浩辰 CAD 直接打开。想要 DWG 格式的话，打开后“另存为 → DWG”即可。

- **图层**按国标线型分好了：01粗实线、02细实线、03虚线、04点画线、05剖面线、06尺寸、07文字、08图框。打印时按图层设线宽，粗实线 0.5，其余 0.25。
- **字体**用的是 AutoCAD 自带的工程字 `gbenor.shx` + `gbcbig.shx`。如果提示找不到字体，选 `gbcbig.shx` 替换即可。
- **尺寸**都是真正的标注对象，可以双击修改。数字是按实测值写进去的，改几何不会自动变，改尺寸时记得一起改数字。
- **表面粗糙度符号没有画**，请按老师的要求补上：没喷漆、发亮的机加工面要标；铸造面在标题栏附近用“其余”加不去除材料的符号统一标。
- 标题栏是按 GB/T 10609.1 的布局简化的 180×56。如果老师给了模板，把图框换成模板的就行。

## 二、SolidWorks

> 说明：.SLDPRT / .SLDASM 是 SolidWorks 的私有格式，只有 SolidWorks 自己能生成，所以这里给的是 STEP 实体加一个宏。宏在你的 SolidWorks 里运行一次，就会生成真正的 SolidWorks 零件和装配体。

### 方法一：运行宏（推荐）

1. 把整个文件夹解压到一个**路径里没有中文**的位置，比如 `D:\QiuFa\`。`step` 文件夹要和 `Build_Ball_Valve.swb` 放在同一层。
2. 打开 SolidWorks，菜单 **工具 → 宏 → 运行**。文件类型选 **SW VBA Macros (*.swb)**，打开 `Build_Ball_Valve.swb`。
3. 宏会自动完成下面几件事：
   - 导入 9 个 STEP 零件，上色，存成 `.SLDPRT`，放在 `solidworks` 文件夹里
   - 新建装配体 `QF-00_Ball_Valve.SLDASM`，把所有零件放到装配位置
   - 固定阀体、阀盖、密封圈、填料、压紧套和 4 个螺栓
   - 给阀杆、阀芯、扳手加配合：三者锁成一体，只能绕阀杆轴转；再加一个“限制角度”配合，范围 90°～180°，也就是只能转 90°
4. 完成后会弹出提示。**用鼠标按住扳手手柄拖动**，阀杆和阀芯会跟着转：手柄顺着管道是“开”（阀芯通孔对着管道），手柄转到和管道垂直是“关”。

如果导入 STEP 时弹出“是否运行输入诊断”，点“否”就行。

**如果扳手转的方向反了**（一拖就卡住，只能往另一边转）：在设计树的“配合”里找到最后那个“限制角度”配合，右键编辑，勾选或取消“反向对齐”。

### 方法二：手动装配（宏跑不通时用）

1. 打开 `step/QF-00_Ball_Valve_Assembly.step`，SolidWorks 会直接生成一个装配体，所有零件都在正确位置上。
2. 在设计树里，对阀杆、阀芯、扳手三个零件**右键 → 浮动**。其余零件保持固定。
3. 依次添加配合（插入 → 配合）：
   - 阀杆的原点 与 装配体原点：**重合**
   - 阀杆的“上视基准面” 与 装配体的“上视基准面”：**重合**
   - 阀芯、扳手各做一遍上面两步
   - 阀杆的“前视基准面” 与 扳手的“前视基准面”：**重合**
   - 阀芯的“前视基准面” 与 扳手的“前视基准面”：**重合**
   - 扳手的“前视基准面” 与 装配体的“右视基准面”：**高级配合 → 角度限制**，最大 180°，最小 90°
4. 拖动扳手，就能开关。

所有零件都是在同一个坐标系里建的：原点在阀芯球心，X 轴沿流道（出口方向），Y 轴沿阀杆向上。所以上面这些配合不需要移动零件。

### 我已经验证过的

- 9 个零件在 OpenCascade 里都是有效实体。装配位置下两两做布尔求交，干涉体积都是 0。
- 扳手按右手定则绕 +Y 轴转，0°～-90° 一路不碰阀体；超过约 -92° 时，半圈凸块撞上凸台上的限位块；往正方向一动就撞。这和实物“只能转 90°”一致。
- 阀芯在 0°、45°、90° 三个位置，和阀体、阀盖、两个密封圈、阀杆都没有干涉。

### 没能验证的

- 我这里没有 SolidWorks，宏是按 SolidWorks API 写的，没法实际跑一遍。宏里要是有哪一步报错，记下弹窗里的提示文字发给我，或者直接用方法二。

## 三、建模的简化

- **螺纹**：都按大径画成光圆柱，没有做真实牙形，这是 SolidWorks 里的常规做法。需要的话，在 SolidWorks 里给它们加“装饰螺纹线”：阀体出口和阀盖都是 M38×1.5，压紧套和凸台是 M24×2，法兰螺孔是 M8。
- **螺孔**：阀体法兰的 4 个 M8 螺孔、凸台的 M24 螺孔都按大径开孔，这样和螺栓、压紧套不会显示干涉。
- **填料**：按一个整体圆环建的。
